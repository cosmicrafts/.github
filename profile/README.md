# Cosmicrafts

Space strategy game by [World of Unreal](https://github.com/worldofunreal). Alpha is live at [cosmicrafts.com](https://cosmicrafts.com).

The economy is Web3: items and currency are assets players own. These are the open parts:

- [cosmicrafts-dao](https://github.com/cosmicrafts/cosmicrafts-dao): on-chain backend and frontend.
- [Adventures-Bevy](https://github.com/cosmicrafts/Adventures-Bevy): game client. Rust, Bevy.
- [Star-Drifter](https://github.com/cosmicrafts/Star-Drifter): space drifting game. Bevy.
- [Cosmicrafts_Quantum](https://github.com/cosmicrafts/Cosmicrafts_Quantum): multiplayer prototype. C#, Photon Quantum.
- [Rush](https://github.com/cosmicrafts/Rush): browser game. Vue.
- [Cosmicrafts3D-2021-DSCVR-Hackathon](https://github.com/cosmicrafts/Cosmicrafts3D-2021-DSCVR-Hackathon): the 2021 prototype that started it.
