Cosmicrafts is a space RTS running **entirely on the Internet Computer**: gasless, Web2-feel gameplay with a real Web3 economy — upgradable ICRC-7 NFTs, ICRC-1 tokens, player profiles with stats, missions and achievements with rewards, and NFT lootboxes.

## Open architecture

- **On-chain backend** (Motoko canisters): game mechanics, player management, NFTs (ICRC-7), currency (ICRC-1), missions, achievements, social features
- **Clients** (Unity/C#, Rust/Bevy): game engine clients plus open prototypes
- **Identity** via [WouID](https://github.com/worldofunreal/wou-id) — cross-game profiles and assets
- **Governance**: on-chain DAO — vote on code merges and treasury
