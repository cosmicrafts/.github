Cosmicrafts is a space real-time strategy game by [World of Unreal](https://github.com/worldofunreal). Fleet battles, ranked ladders, missions and achievements, all tied to a Web3 economy where items and currency are assets players own. The alpha is live and the game is free to play.

![Cosmicrafts Adventures](https://worldofunreal.com/assets/adventures-3d.webp)

[Play at cosmicrafts.com](https://cosmicrafts.com)

## Open source

- [cosmicrafts-dao](https://github.com/cosmicrafts/cosmicrafts-dao): the on-chain architecture of the game. Backend for game mechanics, players, items, currency, missions and governance, with its Vue frontend.
- [Adventures-Bevy](https://github.com/cosmicrafts/Adventures-Bevy): game client in Rust with the Bevy engine. Progression pipeline with XP, equipment and skill nodes, plus mobile (iOS, Android) and WebGL builds.
- [Star-Drifter](https://github.com/cosmicrafts/Star-Drifter): space drifting game built with Bevy.
- [Cosmicrafts_Quantum](https://github.com/cosmicrafts/Cosmicrafts_Quantum): multiplayer prototype on Photon Quantum's deterministic engine. C#.
- [Rush](https://github.com/cosmicrafts/Rush): browser game in the Cosmicrafts universe. Vue.
- [Cosmicrafts3D-2021-DSCVR-Hackathon](https://github.com/cosmicrafts/Cosmicrafts3D-2021-DSCVR-Hackathon): the 3D prototype from 2021 that started the franchise. Unity, C#.
